# 输出交付与恢复

## 按宿主交付

- 宿主支持附件/原生媒体消息：上传本地文件，多个结果全部交付。使用已授权的当前对话，不另发到其他联系人或频道。
- 宿主支持本地预览或文件链接：使用绝对路径的本地媒体预览/可点击文件链接。
- 只有终端：给出绝对路径，明确文件在运行主机上，不假装附件已发送。
- 不假设存在 `message` 工具，不固定输出 `NO_REPLY`，不在交付后强制追问。
- 不向最终用户贴内部结果 URL、密钥或完整调试日志。下载始终由客户端处理。

默认保存到调用时工作目录的 `catsapi-output/`。可以用 `-o /chosen/path/result.png` 指定文件；多图自动加序号，已有文件另取后缀，不覆盖。不要为了调用脚本切到安装目录。

## 如何读取结果

兼容模式：

```text
TASK_ID:<任务ID>
COST:<实际猫币数>
OUTPUT_FILE:<绝对路径>
```

`TASK_ID` 在提交成功后立刻输出并 flush。不能把只有 TASK_ID 的提交回执当成生成完成。

`--json` 模式：生成/恢复输出 NDJSON，每行一个对象：

- `event=submitted`：任务 ID、模型、类型和预估成本；
- `event=resuming`：正在继续哪个旧任务；
- `event=completed`：实际成本和 `output_files`。

查询和 dry-run 命令返回一个普通 JSON 对象或数组。stderr 是进度/错误，退出码非零表示本次命令没有完整完成，不一定表示服务器任务失败。

## 错误决策

| 情况 | 操作 |
| --- | --- |
| 参数/数量不合法 | 查看模型 info 并修正；不改变用户硬性要求 |
| 超预算/余额不足 | 停止，确认预算或让用户自行处理余额；不自动降档或充值 |
| 创建任务的请求断线、无任务 ID | 提交结果未知，先让用户查网页任务记录；不要自动重发 |
| 有任务 ID，等待超时/查询断线 | `--status TASK_ID` 或 `--resume TASK_ID`；不再生成 |
| 任务明确 failed/cancelled | 报告状态；若要新生成，重新确认需求和预算 |
| 任务完成但下载失败 | 同一任务 `--resume TASK_ID`，不重新提交 |
| 附件发送失败 | 检查是否实际已送达，必要时仅重试交付；提供本地路径，不重新生成 |

程序默认每次等待最多 900 秒，可用 `--wait-timeout` 缩短。超时退出码为 6；恢复不需要重新提供 prompt/model，也不扣新任务费用。下载会拒绝空响应/明显 HTML 页面，不把验证码页伪装成成功媒体。

交付前核对返回文件数量、文件可读性，以及宿主能检查的文字/主体/构图。未达到要求时如实说明；不未经授权自动补图或重复生成。只能报告服务端实际返回的成本，不把缺失成本当 0。
