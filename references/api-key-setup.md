# CatsAPI Key 设置

仅在首次使用、用户询问配置或鉴权失败时读取。不把已配置用户重新带入注册问答。

## 一次给清楚步骤

1. 在用户选定的 CatsAPI 站点登录并进入 API Key 页面，创建或复制完整 Key。
2. 让用户通过宿主的秘密配置/环境变量设置 `CATSAPI_API_KEY`，或在私有的本地配置文件中保存；不要发到聊天里。
3. 用户确认设置完成后，可用 `python3 {baseDir}/scripts/catsapi.py --check` 检查鉴权和余额。这是只读 API 请求，不是离线命令，也不生成作品。

不需要逐步询问“注册了吗/创建了吗/复制了吗”。仅询问真正阻塞当前操作的信息。不要在示例命令中展开、打印或代填真实 Key。

## 客户端读取顺序

优先读取进程环境变量；为空时依次静态读取 skill 根目录 `.env`、当前工作目录 `.env`、`~/.catsapi.env`、`~/.zshrc`、`~/.bashrc`、`~/.profile`、`~/.bash_profile`。不会执行 shell 配置。找到了非空但无效的 Key 时不会悄悄换用其他账户。

自建站点可用 `CATSAPI_BASE` 指定地址；除非用户要求，不修改站点地址。密钥和站点必须对应，不应将 Key 发送到其他提供商。

## 出错时

- 缺少 Key：说明如何在私有配置中设置，不要求用户粘贴 Key。
- 401：可能无效、已重置或没有被当前进程读取；请用户检查私有配置后再自检。
- 403：也可能是权限或站点访问限制，不直接断言 Key 错误，不自动重置 Key。
- 余额不足：报告报价与余额，引导用户自行查看站点充值/兑换入口，不承诺赠送规则、重置次数或自动充值。

离线 `--list/--info --offline` 和 `--generate --dry-run` 不需要 Key，可以先帮用户确定模型和参数。
